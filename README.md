## 👋 About me

Software engineer turned cloud specialist, building on **AWS since 2022**: three years as a freelancer on serverless and live video streaming platforms, now in a permanent role on a multi-account AWS Organization. **AWS Certified Solutions Architect – Associate** and **AWS Certified AI Practitioner**.

My portfolio, [abiehler.fr](https://abiehler.fr/?lang=en), is built to the same standard, at a small scale: provisioned by **Terraform**, deployed by **GitHub Actions** with no stored AWS key (federated OIDC role), under a monitored budget. **The site is deployed by the pipeline it describes.**

I am looking for a **DevOps, Cloud or SRE** role where reliability, security and cost are handled from the design stage.
